Why SwanPanel

Built to Fix Everything Broken About Traditional VPNs

Say goodbye to arcane config files, battery-draining client apps, and expensive SaaS subscriptions.

100% Native OS Client Profiles

Employees hate installing clunky 3rd-party apps (OpenVPN, WireGuard client, Cisco AnyConnect) that drain laptop batteries, consume memory, and conflict with OS network settings.

SwanPanel Solution

Native Connectivity: Connect directly from macOS, iOS, Windows, Linux, and Android system settings with native hardware-accelerated IPsec encryption. Zero apps to install.

Zero-Downtime Dynamic RAM Reloads

Editing raw swanctl.conf or ipsec.conf over SSH is dangerous. A single typo crashes the daemon, and reloading static files drops active tunnels for all connected engineers.

SwanPanel Solution

Zero-SSH VICI Control: Reload connections dynamically in RAM via UNIX socket /var/run/charon.vici without dropping live tunnels. Terminate active sessions immediately.

Autonomous Internal PKI (X.509)

Generating Root CAs, signing client certs, and bundling password-protected PKCS#12 (.p12) archives with OpenSSL command lines takes hours of tedious manual crypto labor.

SwanPanel Solution

1-Click Certificate Issuance: SwanPanel automatically provisions 4096-bit RSA Root CAs, signs client certificates, and packages encrypted .p12 bundles with one click.

Sovereign, Open Source & Non-Profit

Commercial Zero-Trust platforms (Tailscale, Cloudflare Zero Trust) charge $5-$20/user/month, lock you into proprietary closed clouds, and route sensitive metadata outside.

SwanPanel Solution

100% Free Forever: Fully self-hosted on your own hardware under GNU AGPL-3.0. Your keys, traffic, and access policies stay entirely under your sovereignty with zero SaaS fees.

Capabilities

Everything You Need for Enterprise Remote Access

Enterprise-grade performance without bloat, complex clusters, or external dependencies.

Native Client Profiles

1-click signed Apple .mobileconfig, Windows PowerShell Add-VpnConnection, Linux NetworkManager, and Android IKEv2 profiles with embedded PKCS#12 certs.

Zero-SSH strongSwan Control

Direct charon daemon management via UNIX socket /var/run/charon.vici using govici IPC. Dynamic in-memory reloads without dropping active tunnels.

Automated Internal PKI

Self-contained X.509 Certificate Authority. Automatically provisions 4096-bit Root CA, issues client certs, and generates password-protected .p12 archives.

Split-DNS & MagicDNS

High-performance embedded DNS server (miekg/dns). Auto-resolves internal devices (.strongnet), supports custom DNS overrides, and forwards recursive queries.

Zero-Trust Access Policies

Granular access control mapping User Groups to Resource Groups. Compiles dynamically into kernel traffic selectors and explicit DROP filters.

Single Self-Contained Binary

Go backend, SQLite database with auto-migration, embedded React 19 SPA, and DNS engine compile into one pure Go executable with zero CGO dependencies.

Installation Guide

Gateway Installation & Setup

Deploy SwanPanel in under 60 seconds with Docker Compose or as a standalone single binary with zero external dependencies.

Firewall & Network Port Requirements

Open the following inbound ports on your gateway or cloud security group (AWS SG, GCP Firewall, Azure NSG):

UDP 500 IKEv2 Negotiation Initial IKE_SA negotiation and Diffie-Hellman key exchange between clients and gateway.
UDP 4500 NAT-Traversal (NAT-T) Encapsulates ESP packets in UDP when clients or gateways are located behind NAT routers.
TCP 8080 Web Control Plane & API SwanPanel admin dashboard, device provisioning portal, and REST API endpoints.
UDP 53 Split-DNS Server Embedded high-performance DNS engine resolving internal hostnames and custom overrides.
Production Setup via Docker Compose 
services:
  swan-panel:
    image: ghcr.io/thienvu18/swan-panel:latest
    container_name: swan-panel
    restart: unless-stopped
    ports:
      - "8080:8080"
      - "53:53/udp"
    volumes:
      - /var/run/charon.vici:/var/run/charon.vici:rw
      - swan-data:/var/lib/swan-panel
    environment:
      - PORT=8080
      - DB_PATH=/var/lib/swan-panel/swanpanel.db
      - LOG_LEVEL=INFO
volumes:
  swan-data:

Initial Gateway Configuration Walkthrough

Follow these 5 simple steps to bootstrap your production gateway after launching SwanPanel:

01

Root Admin Sign In

Open http://<GATEWAY_IP>:8080. Log in using default credentials admin@swanpanel.internal / Admin@SwanPanel123! and change your password.

02

Set External Domain

In Server Settings, input your gateway's public domain name (e.g. vpn.example.com). This FQDN is embedded into all generated client profiles.

03

Define IP Pool

Allocate virtual VPN client address pools (e.g. 10.50.0.0/16). SwanPanel assigns dedicated IP subnets to user and resource groups.

04

Internal PKI Setup

SwanPanel automatically issues an internal 4096-bit RSA Root CA and signs gateway certificates, eliminating manual OpenSSL scripts.

05

Live VICI Dynamic Socket

Verify connection to /var/run/charon.vici. Rules and devices reload dynamically in RAM without ever restarting the daemon or dropping active tunnels.

End-User Guide

Native VPN Client Connection Guide

Connect in seconds using built-in OS clients on macOS, iOS, Windows, Linux, and Android. Zero third-party apps required.

Hardware-Accelerated IPsec

Native AES-256-GCM encryption runs directly in the OS kernel with zero CPU virtualization overhead.

Zero Battery & RAM Bloat

No background daemon or tray agent draining device battery. Seamless sleep, wake, and standby.

MOBIKE Seamless Roaming

Roam seamlessly between Wi-Fi and 4G/5G cellular connections without dropping active sessions (RFC 4555).

Automatic Split-DNS

Only internal corporate domains (.strongnet) route through VPN DNS, keeping personal browsing completely untouched.

Select Your Operating System

Choose your platform for exact step-by-step connection instructions:

macOS & iOS
.mobileconfig
  1. Log In: Access SwanPanel and locate your device under Resources.
  2. Download: Click "Download Profile (.mobileconfig)" containing your embedded certificate.
  3. Install: Double-click profile -> Open System Settings -> Profiles -> Click Install.
  4. Connect: Toggle VPN from your Mac menu bar or iOS Control Center.
Windows 10 & 11
PowerShell .ps1
  1. Log In: Access SwanPanel and choose Windows as platform.
  2. Download: Download the tailored setup.ps1 script and certificate bundle.
  3. Run Script: Right-click setup.ps1 -> Select "Run with PowerShell as Administrator".
  4. Connect: Click Network icon on Taskbar -> Select SwanPanel -> Connect.
Linux
NetworkManager
  1. Download: Download the .nmconnection profile and certificates package.
  2. Install: Copy file to /etc/NetworkManager/system-connections/ with 600 permissions.
  3. Reload: Execute sudo nmcli connection reload.
  4. Connect: Run nmcli connection up <DeviceName> or toggle via desktop UI.
Android
IKEv2 RSA / strongSwan
  1. Download: Download the .p12 certificate bundle onto your device.
  2. Install Cert: Settings -> Security -> Install Certificate -> VPN & App User Certificate.
  3. Password: Enter the PKCS#12 bundle decryption password shown in SwanPanel.
  4. Connect: Create an IKEv2/IPSec RSA connection in native VPN settings and connect.
