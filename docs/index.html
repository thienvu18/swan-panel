The Problems We Solve

Say Goodbye to VPN Friction & SaaS Extortion

Why traditional VPN administration and commercial Zero-Trust SaaS fail modern engineering teams.

Arcane Config Files & Risky Downtime

Editing raw swanctl.conf or ipsec.conf text files over SSH is error-prone. A single syntax mistake crashes the daemon, and reloading static files drops active tunnels for all connected engineers.

SwanPanel Solution

Zero-SSH management via /var/run/charon.vici. Dynamic in-memory reloads execute in RAM with zero tunnel interruptions, live session termination, and real-time telemetry.

The 3rd-Party VPN Client Nightmare

Users hate installing clunky 3rd-party apps (OpenVPN, WireGuard client, Cisco AnyConnect) that consume RAM, drain laptop batteries, and conflict with native OS networking.

SwanPanel Solution

100% Native OS profiles. Apple .mobileconfig (1-click install in macOS/iOS Settings), Windows PowerShell Add-VpnConnection, Linux NetworkManager, and Android IKEv2. Zero software to install.

Manual PKI & Certificate Mismatches

Generating X.509 Root CAs, signing client certificates, and bundling password-protected PKCS#12 (.p12) archives with OpenSSL command lines requires deep crypto expertise and hours of manual labor.

SwanPanel Solution

Autonomous internal PKI. SwanPanel automatically provisions 4096-bit RSA Root CAs, issues client certificates, and packages encrypted .p12 bundles with one click.

Expensive SaaS Lock-In & Privacy Leaks

Commercial platforms (Tailscale, Cloudflare Zero Trust, Twingate) charge high per-seat monthly subscriptions, lock you into proprietary closed-source controllers, and route metadata through external clouds.

SwanPanel Solution

100% Self-Hosted, Sovereign, and Non-Profit. Free forever under AGPL-3.0. Your keys, access policies, and traffic stay entirely on your servers.

Core Capabilities

Engineered for Sovereign Zero-Trust Infrastructure

Enterprise-grade performance without bloat, subscriptions, or external dependencies.

100% Native Client Provisioning

Deliver signed Apple .mobileconfig profiles, Windows PowerShell scripts, Linux NetworkManager files, and Android IKEv2 profiles with embedded PKCS#12 certificates. Users connect directly from OS system settings.

Zero-SSH strongSwan Control

Communicate directly with strongSwan's charon daemon via UNIX socket /var/run/charon.vici using the binary govici protocol. Reload connections in RAM without dropping active tunnels and terminate sessions instantly.

Automated Internal PKI

Autonomous X.509 Certificate Authority. Automatically provisions 4096-bit RSA Root CAs, signs client certificates, and packages password-protected PKCS#12 bundles without OpenSSL CLI steps.

Configurable Split-DNS & MagicDNS

Integrated high-performance DNS server (miekg/dns). Dynamically resolves internal device hostnames (.strongnet, .internal), supports custom DNS overrides, and recursively forwards queries upstream.

Dynamic Zero-Trust Policies

Define granular access control rules mapping User Groups to Resource Groups. SwanPanel compiles policies dynamically into kernel traffic selectors and explicit DROP filters, eliminating lateral movement.

Single Self-Contained Binary

The entire control plane—Go backend, SQLite database with auto-migration, embedded React 19 SPA, PKI, and DNS engine—compiles into a pure Go static executable with zero CGO dependencies.

Get Started in 60 Seconds

Deploying SwanPanel is Ridiculously Simple

From a bare Linux VPS to a production-ready zero-trust VPN in three quick steps.

01

Run 1-Line Installer

Run curl -sSL https://raw.githubusercontent.com/thienvu18/swan-panel/main/install.sh | sudo bash. The script installs strongSwan, tunes kernel forwarding, and starts the systemd service.

02

Open Web Control Plane

Navigate to http://<SERVER_IP>:8080. Log in with the default administrator credentials, configure your external hostname, and invite your team.

03

Download Native Profiles & Connect

Add personal or company devices with one click. Download Apple .mobileconfig, Windows PowerShell, or Linux profiles and connect directly from OS settings.
