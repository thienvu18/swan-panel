Capabilities

Engineered for Sovereign Zero-Trust Infrastructure

No proprietary clients. No mandatory SaaS cloud subscriptions. No complex orchestration clusters.

100% Native Client Provisioning

Generate native Apple .mobileconfig, Windows PowerShell Add-VpnConnection, Linux NetworkManager, and Android IKEv2 profiles with embedded PKCS#12 client certificates. Users never install third-party background software.

Zero-SSH strongSwan Control

Manage the daemon dynamically via UNIX socket /var/run/charon.vici using the official govici IPC protocol. Reload connections in RAM without dropping active tunnels, terminate sessions, and monitor SA states live.

Automated Internal PKI

Zero-touch autonomous X.509 Certificate Authority. Automatically provisions 4096-bit RSA Root CAs, signs client certificates, and packages password-protected PKCS#12 bundles without OpenSSL CLI steps.

Configurable Split-DNS & MagicDNS

Integrated high-performance DNS server (miekg/dns). Automatically maps internal hostnames (e.g. .strongnet, .internal) directly to assigned virtual IPs, with support for custom DNS overrides and recursive upstream forwarding.

Dynamic Zero-Trust Policy Engine

Define granular access rules mapping User Groups to Resource Groups. SwanPanel compiles policies dynamically into kernel traffic selectors and explicit DROP filters, eliminating lateral movement.

Single Self-Contained Binary

The entire control plane—Go backend, SQLite database with auto-migration, embedded React 19 SPA, PKI, and DNS engine—compiles into a pure Go static executable with zero CGO dependencies.
