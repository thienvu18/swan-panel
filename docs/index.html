Why SwanPanel

Built to Fix Everything Broken About Traditional VPNs

Say goodbye to arcane config files, battery-draining client apps, and expensive SaaS subscriptions.

The Old Way: Heavy Client Apps

Employees hate installing clunky 3rd-party apps (OpenVPN, WireGuard client, Cisco AnyConnect) that drain laptop batteries, consume memory, and conflict with OS network settings.

SwanPanel Solution

100% Native Connectivity: Connect directly from macOS, iOS, Windows, Linux, and Android system settings with native hardware-accelerated IPsec encryption. Zero apps to install or maintain.

The Old Way: Fragile SSH Config Files

Editing raw swanctl.conf or ipsec.conf over SSH is dangerous. A single typo crashes the daemon, and reloading static files drops active tunnels for all connected remote engineers.

SwanPanel Solution

Zero-SSH Dynamic VICI Control: Reload connections dynamically in RAM via UNIX socket /var/run/charon.vici without dropping live tunnels. Terminate unauthorized sessions immediately.

The Old Way: Expensive SaaS Lock-In

Commercial Zero-Trust platforms (Tailscale, Cloudflare Zero Trust) charge $5-$20/user/month, lock your infrastructure into proprietary closed clouds, and route sensitive network metadata outside.

SwanPanel Solution

100% Free & Self-Hosted: Deploy on your own servers under GNU AGPL-3.0. Your keys, traffic, and access policies stay entirely under your sovereignty with zero recurring subscription fees.

Capabilities

Enterprise Zero-Trust Capabilities Built-In

Everything you need for enterprise remote access without bloated clusters or external dependencies.

1-Click Native Client Provisioning

Auto-generate signed Apple .mobileconfig, Windows PowerShell Add-VpnConnection scripts, Linux NetworkManager profiles, and Android IKEv2 cert bundles.

Autonomous Internal PKI (X.509)

Built-in Certificate Authority automatically provisions 4096-bit RSA Root CAs, signs client certs, and packages encrypted .p12 bundles without manual OpenSSL scripts.

Split-DNS & MagicDNS Engine

Embedded high-performance DNS server (miekg/dns) auto-resolves internal devices (.strongnet) and custom overrides while keeping personal web traffic private.

Micro-Segmented Access Policies

Granular zero-trust access control mapping User Groups to Resource Groups, compiled dynamically into kernel traffic selectors and DROP filters.

Dynamic RAM Control via VICI

Direct strongSwan charon daemon management over UNIX socket /var/run/charon.vici. Dynamic RAM reloads without dropping live engineer tunnels.

Single Self-Contained Binary

Go backend, SQLite database with auto-migration, embedded React 19 SPA, and DNS engine compile into one pure Go executable with zero CGO dependencies.

docker-compose.yml 
services:
  swan-panel:
    image: ghcr.io/thienvu18/swan-panel:latest
    container_name: swan-panel
    restart: unless-stopped
    ports:
      - "8080:8080"
      - "500:500/udp"
      - "4500:4500/udp"
      - "53:53/udp"
    volumes:
      - /var/run/charon.vici:/var/run/charon.vici:rw
      - swan-data:/var/lib/swan-panel
