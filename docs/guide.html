1. Installation & Setup

System Requirements & Port Matrix

SwanPanel is a lightweight, single-binary control plane written in pure Go. It coordinates strongSwan's high-performance IPsec kernel module without requiring Java, Node.js runtimes, or external database servers.

Network Firewall & Port Mapping

Open the following inbound ports on your cloud firewall (AWS Security Group, GCP Firewall, Cloudflare, or local iptables):

UDP 500 IKEv2 Negotiation Initial Diffie-Hellman key exchange and SA negotiation.
UDP 4500 NAT-Traversal (NAT-T) Encapsulates ESP packets in UDP when devices are behind NAT.
TCP 8080 Web Control Plane & API Admin dashboard and client device provisioning endpoint.
UDP/TCP 53 Split-DNS Server High-performance internal DNS resolving .strongnet domains.

1-Line Automated Production Installer

The recommended deployment method for Ubuntu, Debian, RHEL, Rocky Linux, AlmaLinux, and Fedora. The installer automatically detects your distribution, installs strongSwan with the VICI plugin, tunes Linux kernel packet forwarding, generates an initial PKI CA, and registers a systemd service:

bash installer
curl -sSL https://raw.githubusercontent.com/thienvu18/swan-panel/main/install.sh | sudo bash

Once complete, access your control plane at http://<SERVER_IP>:8080.

Production Docker Compose Deployment

If you prefer containerized workloads, run SwanPanel via Docker Compose. Ensure the host has the strongSwan VICI UNIX socket mapped at /var/run/charon.vici:

docker-compose.yml 
services:
  swan-panel:
    image: ghcr.io/thienvu18/swan-panel:latest
    container_name: swan-panel
    restart: unless-stopped
    ports:
      - "8080:8080"
      - "500:500/udp"
      - "4500:4500/udp"
      - "53:53/udp"
    volumes:
      - /var/run/charon.vici:/var/run/charon.vici:rw
      - swan-data:/var/lib/swan-panel
    environment:
      - PORT=8080
      - DB_PATH=/var/lib/swan-panel/swanpanel.db
      - LOG_LEVEL=INFO
volumes:
  swan-data:

Configuration & Environment Variables

Configure SwanPanel via environment variables or /etc/swan-panel/config.env:

# Web Server Binding
PORT=8080
HOST=0.0.0.0

# Database Storage (Pure Go SQLite)
DB_PATH=/var/lib/swan-panel/swanpanel.db

# strongSwan IPC Socket
VICI_SOCKET=/var/run/charon.vici

# Split-DNS Engine
DNS_PORT=53
DNS_DOMAIN=strongnet
UPSTREAM_DNS=1.1.1.1,8.8.8.8

# Security & Logs (DEBUG, INFO, WARN, ERROR)
LOG_LEVEL=INFO

TLS Termination & Reverse Proxy

For production security, terminate HTTPS via Caddy or Nginx:

# Caddyfile Example
vpn.yourcompany.com {
    reverse_proxy localhost:8080
}
2. Administrator Guide (Visual Walkthrough)

Initial Administrator Sign In

Navigate to http://<SERVER_IP>:8080. Log in using the default administrative credentials:

  • Email: admin@swanpanel.internal
  • Default Password: Admin@SwanPanel123!

You will be prompted to replace this default secret immediately upon your first sign in to ensure zero-trust compliance.

Dashboard & Gateway Live Status

The Dashboard provides instantaneous visibility into your strongSwan daemon: VICI UNIX socket connection health, active Security Associations (IKE_SA / CHILD_SA), connected client devices, and realtime RX/TX throughput metrics.

Subnets & IP Pool Allocation

In Resources → Subnets, configure virtual VPN client address pools (e.g. 10.50.0.0/16) and register protected private subnets (e.g. 10.60.10.0/24 for Production, 10.60.20.0/24 for Staging).

Device Inventory & Client Profile Provisioning

Every endpoint connecting to SwanPanel is tracked under Resources → Devices. When you register a new device, SwanPanel's internal PKI automatically generates an X.509 client certificate and prepares platform-specific configuration profiles (.mobileconfig for Apple, PowerShell for Windows, NetworkManager for Linux).

User Directory & Role-Based User Groups

Manage local users and organize them into functional groups (e.g. Engineering, DevOps, Contractors, Sales). Access rules are enforced at the group level to maintain zero-trust segmentation.

Zero-Trust Access Rules Engine

Under Access Rules, define explicit ALLOW and DENY policies mapping User Groups to Resource Groups. When you save a rule, SwanPanel dynamically recompiles Linux kernel traffic selectors and pushes the changes into RAM via the VICI socket without dropping any live tunnels.

Split-DNS Engine & Hostname Overrides

SwanPanel includes an embedded DNS server powered by miekg/dns. It automatically registers connected devices under <hostname>.strongnet and allows administrators to define custom A and CNAME record overrides for internal services (e.g. k8s.internal → 10.60.10.100).

Enterprise Single Sign-On (OIDC SSO)

Connect your organization's identity provider (Google Workspace, Microsoft Entra ID, Okta, Keycloak, or Auth0) using standard OpenID Connect (OIDC).

Server Settings & VICI Socket Tuning

Under Server Settings, set your gateway's public FQDN (e.g. vpn.company.com), configure default DNS search domains, and verify UNIX socket connectivity to /var/run/charon.vici.

Real-Time System Audit & Kernel Logs

Stream structured system and charon daemon logs directly in the browser over Server-Sent Events (SSE). Filter by severity level (DEBUG, INFO, WARN, ERROR) or search by client IP address.

3. End-User VPN Guide

Why SwanPanel Uses 100% Native OS Clients

Unlike legacy VPN solutions that force employees to install bulky, battery-draining client applications, SwanPanel leverages the native IKEv2/IPsec engine built directly into every modern operating system.

Hardware-Accelerated IPsec

Native AES-256-GCM encryption runs directly in the OS kernel with zero CPU virtualization overhead.

Zero Battery & RAM Bloat

No background tray agent or daemon draining laptop battery. Seamless sleep, wake, and standby.

MOBIKE Seamless Roaming

Roam seamlessly between Wi-Fi and 4G/5G cellular connections without dropping active sessions (RFC 4555).

Automatic Split-DNS

Only internal corporate domains (.strongnet) route through VPN DNS, keeping personal browsing completely untouched.

Apple Ecosystem: macOS & iOS (.mobileconfig)

SwanPanel packages your client certificate, private key, and Root CA trust chain into a single signed Apple configuration profile (.mobileconfig).

  1. Step 1 (Download): Log in to SwanPanel and click Download Profile (.mobileconfig) for your device.
  2. Step 2 (Install): Double-click the file. Open System Settings → Privacy & Security → Profiles, double-click the profile, and click Install.
  3. Step 3 (Connect): Click the native VPN toggle in your Mac menu bar or iOS Control Center. You are securely connected!

Microsoft Windows 10 & 11 (PowerShell Script)

SwanPanel generates an automated, idempotent PowerShell script that imports the Root CA, installs your machine certificate, and creates the native Windows VPN connection:

  1. Step 1 (Download): Download your customized setup.ps1 and certificate bundle from SwanPanel.
  2. Step 2 (Run): Right-click setup.ps1 and select Run with PowerShell as Administrator.
  3. Step 3 (Connect): Click the Network icon on your Taskbar, select SwanPanel-VPN, and click Connect.

Linux Desktop (NetworkManager & nmcli)

On Ubuntu, Fedora, Debian, and Arch desktops, SwanPanel integrates with native NetworkManager: 

# 1. Copy profile to NetworkManager system configuration
sudo cp SwanPanel.nmconnection /etc/NetworkManager/system-connections/
sudo chmod 600 /etc/NetworkManager/system-connections/SwanPanel.nmconnection

# 2. Reload connections and activate
sudo nmcli connection reload
sudo nmcli connection up SwanPanel

Google Android (Native IKEv2 RSA)

Android connects via native IKEv2/IPSec RSA using standard system settings:

  1. Step 1: Download the .p12 bundle from SwanPanel onto your Android device.
  2. Step 2: Go to Settings → Security → Encryption & Credentials → Install a Certificate → VPN & App User Certificate.
  3. Step 3: Select the file, enter the decryption password shown in SwanPanel, and tap OK.
  4. Step 4: In Android VPN settings, add an IKEv2/IPSec RSA connection and tap Connect.
