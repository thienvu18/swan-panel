The gateway host's default Go 1.26.10 with `GOTOOLCHAIN=local` is older than the Go 1.27.4 minimum declared by `go.mod`; the Go checks above therefore explicitly enable toolchain selection. These checks do not establish visual or real-gateway acceptance.

```sh
cd ui
npm ci
npm run check:i18n
npm test
npm run build
cd ..
go test ./...
go vet ./...
```

Check at least one real browser with keyboard-only navigation (Tab, Shift+Tab, Enter, Escape), a screen reader's table/action names, 200% zoom and touch horizontal scrolling. A static unit test is not a substitute for those checks. Re-run gateway apply/retry and a real native Android connection only if the deployment environment is safe for those actions.

Do not mark this document PASS until the actual build SHA, screenshots/test evidence and any outstanding defects are recorded. Do not publish the v1.0.1 release tag before all release gates pass.
